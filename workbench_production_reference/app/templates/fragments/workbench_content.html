Why this feels persistent

This screen stores user tab state in Redis-backed sessions and durable workbench state in PostgreSQL. The page is not a client SPA, so tab changes only replace this content area instead of re-mounting the whole application.

No debug reloader
Run with Waitress on Windows or Gunicorn in containers, never Flask debug reload.
No in-memory-only state
Selections, tabs, and latest task references are persisted server-side.
Background jobs
Long preprocessing work moves to Celery so the request thread stays fast.
